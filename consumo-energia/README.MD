# Consumo De Energia

## Descrição

Programa feito para calculo de watts consumidos por elétrodomestico por mês e custo mensal por watt dado em reais

## Tecnologias utilizadas

- Python

## Como executar

Para a sua execução deve primeiro informar um elétrodomestico, a seguir o custo que ele consume em watts, após isso informar a quantidade de horas diarias que o eletrônico é utilizado

## Formulas

Para fazer o calculo de Watts é utilizado a seguinte formula:
consumomensal = (potencia _ consumoHoras _ 30) / 1000

A seguir o programa faz o calculo com o consumo mensal em Kwh e calcula o preço pelo valor fixo do custo, com a seguinte formula:
gastomensal = (consumomensal \* custo)
