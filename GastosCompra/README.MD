## Descrição

Programa feito com o intuito de servir para calcular o preço de compras com o desconto de forma automatica.

## Tecnologias utilizadas

## Como executar

Para sua execução, basta inserir os dados iniciais pedidos no input, a seguir o programa dará o resultado final da sua compra com o valor descontado e com a porcentagem que estará sendo descontada
