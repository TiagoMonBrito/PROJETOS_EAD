# Pesquisa Empresa

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?style=for-the-badge&logo=python)
![Status](https://img.shields.io/badge/Status-Em%20desenvolvimento-orange?style=for-the-badge)

Este programa coleta nome, idade e avaliação de candidatos sobre a empresa.
Ao final, mostra quantas respostas foram excelentes ou ruins.

## Objetivo

O projeto tem como finalidade registrar a opinião dos participantes sobre a empresa, organizando as respostas em um resumo final simples e rápido.

## Como executar

Apenas preencha o formulario de acordo com seu nome, idade, e respectiva avaliação, dada em : 1 - "EXCELENTE" ; 2 - "BOM" ; 3 - "RUIM"
